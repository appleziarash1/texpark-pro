How to open it

To run on the phone

  1. Take the texpark-pro.html file out of the ZIP.
  2. Send the file to your phone via WhatsApp / email, or copy it over USB.
  3. Open the file on the phone (Files app → tap the file) → it opens in Chrome.
  4. Browser menu (⋮) → "Add to Home screen". It becomes an icon — and opens offline.
After opening it once on the phone, set PH in Settings → Device Tag. On the PC set PC. Then memo numbers will never clash.

To run on the PC

  1. Open the ZIP with Right click → Extract All.
  2. Inside the texpark-pro-app folder, double-click OPEN_APP.bat — the app opens in the browser. This file installs nothing; it just opens the app. Node.js is not needed.
  3. Want a desktop shortcut? Run CREATE_DESKTOP_SHORTCUT.bat — it adds an icon to the desktop. (Running from the shortcut needs Node.js; otherwise bookmark index.html in the browser.)
Want a real Windows .exe app? Install Node.js LTS and run npm run dist in the folder — a setup file is created in the dist folder, installable on another PC.

If hosting gives "Page not found" (404)

That 404 is Netlify's message — the site is running, but there is nothing at that address. The most common cause: the whole ZIP was dropped. Netlify unzips it, so the website root does not hold index.html — it holds texpark-pro-app/index.html (one folder down). Going to "/" therefore gives a 404.

Fix: for hosting use the texpark-hosting.zip file — it has all files at the root, so the app starts as soon as you open /. Or drag the folder (not the contents inside texpark-pro-app — the whole folder).

Getting a 404 on a page? In Netlify, check the Deploys tab (not Settings → Build & deploy → Deploy Preview) to see whether the latest deploy succeeded. After a new drop, wait 20-30 seconds.

Install steps and all troubleshooting are in ANDROID_BANGLA.txt (inside the ZIP).

How the app updates itself

The APK carries a working version inside. When the app opens it asks your site — "anything new?" If so it downloads it by itself, and the next time the app opens the new version runs.

No internet? No problem — the built-in version runs. When the network returns it fetches the update next time.

If something goes wrong? Press and hold the app's Back button — a menu opens. Tap "Return to built-in app" and the app runs again. Your data is not erased.
