Kivabe khulbo

Phone-e chalate

  1. ZIP-er bhitor thika texpark-pro.html file ta ber korun.
  2. File ta WhatsApp / email kore nijer phone-e pathaan, ba USB diye kopi korun.
  3. Phone-e file ta khulun (Files app → file-e tap) → Chrome browser e khulbe.
  4. Browser-er menu (⋮) → "Add to Home screen" chepun. Icon hoye jabe — internet charao khulbe.
Phone-e ekbar khular por Settings → Device Tag e PH boshiye din. Ar PC-te PC. Tahole memo number kokhono clash korbe na.

PC-te chalate

  1. ZIP ta Right click → Extract All diye khulun.
  2. texpark-pro-app folder-er bhitor OPEN_APP.bat e duibar click korun — app browser-e khulbe. Ei file ta kichu install kore na, sudhu app ta kholay. Node.js lage na.
  3. Desktop-e shortcut chai? CREATE_DESKTOP_SHORTCUT.bat chepe nin — desktop-e icon hoye jabe. (Shortcut-er maddhome chalate Node.js lage; na thakle browser-e index.html bookmark kore rakhen.)
Windows-er ashol .exe app chan? Node.js LTS install kore folder ta te npm run dist chepun — dist folder-e setup file toiri hobe, jeta onno PC-te install kora jabe.

Permanent link ta ki ei link ta?

Na. Ei sandbox-er link (work-1-...prod-runtime.all-hands.dev) temporary — kichudin por bondho hoye jabe. Tai download kore nijer kache rakha shobcheye bhalo. Ar permanent link chai hole texpark-pro-app folder ta app.netlify.com/drop e drag korun — free permanent link paben, PC + phone dutotei khulbe.

Ekta jinis mone rakhben: Netlify te login na kore drag korle, site ta kichudin por nijei "Password protected site" wall-er pichone chole jay — ar oi password apnar jana thakbe na. Tai age free account khulun (shudhu email lagbe), tarpor drop korun. Tahole site ta apnar thakbe, password wall ashe na, ar update-o korte parben. Detail HOSTING_BANGLA.txt-e.

Hosting korar somoy jodi "Page not found" (404) ashe

Ei 404 ta Netlify-r message — mane site ta cholche, kintu oi address-e kichu nei. Shobcheye common karon: pura ZIP ta drop kora hoyeche. Netlify ZIP ta nijei khule fele, tokhon website-er root-e index.html thake na — thake texpark-pro-app/index.html (ek folder bhitore). Tai "/" e giye 404 ashe.

Samadhan: hosting-er jonno texpark-hosting.zip file ta use korun — eitate sob file root-e ache, tai / khulei app chalu hobe. Ba folder-ta drag korun (texpark-pro-app folder-er bhitor e na dhuke, pura folder ta).

Kono ekta page-e giye 404 ashe? Netlify te Settings → Build & deploy → Deploy Preview na, borong Deploys tab theke dekhen site ta sobcheye last-e thik vabe deploy hoyeche kina. Notun drop korle 20-30 second opei thakun.
