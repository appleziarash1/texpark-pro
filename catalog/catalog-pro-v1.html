PC + phone together — data is never lost

These five things are handled, so running two machines together never mixes up the accounts, and one machine can never erase the other's work.

🔒Memo numbers never clash

Before, the PC and phone both made TXP/SM/<date>-001, and the sheet saves by that number — so one memo overwrote the other. Now the number carries a device tag:

  • PC: TXP/SM/2026/09/22-PC001
  • Phone: TXP/SM/2026/09/22-PH001
  • Purchase numbers work the same way (PC/PH)
  • If the tag is blank it picks PC/PH automatically

♻Sync now verifies, and pulls back too

Before, sync only pushed — the response could not be read, so "sent" did not mean "saved". And there was no way to pull anything back.

  • It will not say "synced" without a reply
  • Offline jobs wait in a queue and are sent automatically when it returns
  • Data can be restored from the cloud

⌛Syncs by itself — every 30 seconds new

Before, writing a memo on the PC meant closing and reopening the app on the phone to see it. Now, while the app is open it pulls new data every 30 seconds by itself.

  • Auto-pull every 30 seconds while the app is open
  • With nothing new the screen is never disturbed — you stay where you are typing
  • Minimizing the app stops the polling — it does not burn data in the background
  • Same on the Android app — write on the PC and it reaches the phone by itself

🌐Company, settings, users — all sync new

Before, only memos and stock synced. The company name, memo prefix, low-stock level and staff logins had to be set again on every machine.

  • Set the company details (name, phone, address, BIN, VAT) once and they apply everywhere
  • A new user created on the PC can sign in on the phone too
  • A password changed on the PC works on the phone too
  • Whichever value is newer wins — the old one never erases the new one

📱Each device keeps its own settings new

Sync URL, device tag and auto-pull are not copied from one device to another. Before, syncing these meant the phone took the PC's tag and its memo numbers mixed with the PC's.

  • The sync URL does not sync — one device's URL never leaks to another
  • The device tag (PC/PH) stays its own — memo numbers never clash
  • Auto-pull on/off is separate per device
  • Every other business setting does sync — data is not lost

⚠If sync is off, the Dashboard says so new

If a device is not yet paired with the sheet, the Dashboard can look like a brand-new shop with all zeros — and it seems the data is gone. Now it does not stay silent: a red caution banner at the top of the page says this device's data is not reaching the others, and how to fix it.

  • It says that what is on screen is only demo products, not your data

📈Fix old memos' wrong profit new

When a memo is saved, its buying price is written into the memo. So if an old memo was saved with a wrong cost, fixing the product's price does not fix that old memo's profit by itself. Now it can be corrected in one click from the Backup / Data page.

  • Fixes only profit and cost — sales, qty, due and stock are untouched
  • Running it again changes nothing — no double-correction

How to run it

On the PC (Windows)

  1. Double-click START_APP.bat — the app opens.
  2. Want a desktop shortcut? Run CREATE_DESKTOP_SHORTCUT.bat.
  3. You can also start it with npm start.
To build a Windows .exe installer: npm run dist — you get a portable build + nsis setup in the dist folder.

On the phone / a new PC

  1. Send the single file texpark-pro.html to the phone (email/WhatsApp/USB).
  2. Open the file in the browser, then tap "Add to Home screen".
  3. It becomes an app icon — and opens without internet (offline).
After installing on the phone, set PH in Settings → Device Tag, and PC on the PC. Then memo numbers will never clash.

Do not add a /* /index.html 200 rewrite on Netlify. With that setting, any unknown path (such as js/app.js) returns index.html instead, and the phone's app cannot recognise a new version — it stays stuck on the old one forever. This mistake happened before: the old Netlify site (keen-rolypoly-3f9aa4.netlify.app) is still stuck at 2026-09-22.6. Do not use that address any more.
Careful: dragging to Netlify without logging in makes the site move behind a "Password protected site" wall after a few days, and you will not know that password. So open a free account and drop while logged in.
