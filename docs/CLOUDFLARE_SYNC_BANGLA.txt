# Texpark Pro — Cloudflare live sync (Firebase chara, nijer control-e)

> **STATUS: LIVE (2026-10-13).** Worker deploy hoye geche:
> `https://texpark-sync.apple-ziarash1.workers.dev` — `js/cloudflare-config.js`-e
> `backend:'cloudflare'` ar URL bosa noa hoyeche, dutoi live site-e cholche. Shop token
> repo-te **nai** — prottek device private `#cloud=` link diye ekbar niye ney.
> Ekta bug chhilo: deploy step `echo` diye secret bosato, tai `AUTH_TOKEN`-er seshe
> ekta newline juthe chhilo ar sothik token-o 401 dicchilo. Ekhon `printf` + trim
> diye thik kora hoyeche.

Ei guide ta diye live sync ta **Firebase theke Cloudflare-e** sora jabe. Data thakbe
**tomar nijer Cloudflare account-e** — Google Sheet ba Firebase-er upor kono nirbhor
thakbe na. Live update aro **druto** hobe: ek device-e likhle onno device-e **~0.1
second**-e pouchay (WebSocket push, poll na).

> Cloudflare-er free plan-i jotheshto. Durable Object + Workers 2025 theke free.
> Ekhon ja cholche (Sheet + Firebase) ta **thakbe** — kichu bhange na. Aponi chalu
> korle seta Cloudflare-e jabe, na korle purono moto-i cholbe.

---

## Eta ki kore

- **Cloudflare Worker** ekta chhoto server, ar **Durable Object** shop-er sob record
  (customer, product, memo...) rakhe SQLite-e.
- Kono device likhle Worker sathe-sathe onno device-gulote ekta **WebSocket** message
  pathay. Tai 1-2 second na, **tens of milliseconds**.
- Auth ekta **shop token**. Eta `js/cloudflare-config.js`-e bake kora thake, tai
  device-e kichu type korte hoy na — site khullei cholbe.

## Apnar ki korte hobe (click-by-click)

### Step 1 — Cloudflare account
1. https://dash.cloudflare.com/signup (email diye free account)
2. Dashboard-e **Workers & Pages** e jaan, **Account ID** copy korun.

### Step 2 — API token
1. https://dash.cloudflare.com/profile/api-tokens
2. **Create Token** → **"Edit Cloudflare Workers"** template → Continue → Create.
3. Token ta ekbar-i dekhay — copy kore rakhun.

### Step 3 — GitHub repo-te 3 ta secret
Repo: `appleziarash1/texpark-pro` → **Settings → Secrets and variables → Actions**:
- `CLOUDFLARE_API_TOKEN` = Step 2-er token
- `CLOUDFLARE_ACCOUNT_ID` = Step 1-er Account ID
- `CLOUDFLARE_SYNC_TOKEN` = **nijer ekta lamba gopon token** (e.g. 32 random
  character). Eta-i shop-er password. Keu jodi jene jay, tara shop dekhte parbe —
  tai eta **karo shathe share korben na**.

### Step 4 — Chalu korun
`cloudflare/` folder ta push korle **Actions → "Deploy sync backend"** apni-i run
hobe (ba **Run workflow** chepe hate chalu korun). Sesh hole ekta URL pabben:

```
https://texpark-sync.<tomar-subdomain>.workers.dev
```

### Step 5 — Client ta sei URL-er dike ghuray din
`texpark-pro/js/cloudflare-config.js` khulun, `backend` ar `url` bosan
(**token ta khali rakhen** — eta public repo, token ekhane likhben na):

```js
window.CLOUDFLARE_SYNC = {
  backend: 'cloudflare',
  url: 'https://texpark-sync.<tomar-subdomain>.workers.dev',
  token: ''          // khali: token asbe private link diye (Step 6)
};
```

Tarpor commit + push.

### Step 6 — Prottek device-e token din (ek bar, kono typing chara)
Token ta public repo-te thakle keu-i tomar shop porte parto, tai token ta
**private setup link** diye dewa hoy (Firebase-er moto-i):

1. Ekta device-e site khulun → **Settings → Cloud sync → Connect**.
2. Niche **"Get setup link"** chepun — link ta asbe ei rokom:
   `https://appleziarash1.github.io/texpark-pro/#cloud=<gopon>`
   (link-er modhye tomar token ache; eta **karo shathe share korben na**).
3. Oi link ta **nijer phone-e** (WhatsApp/SMS) pathan, ar sekhane **ekbar khulun**।
   Device ta token nijer modhye rekhe ney, ar address bar theke secret muchhe jay.
   Erpor oi device **Firebase chara** live sync-e cholbe, badge **"☁ Cloudflare live"**।

> Jodi link chara sudhu token-i paste korte chan, tahole Connect box-e token ta
> likhe Connect chepun — kaaj korbe.

## Bhalo dike (verify) korbo kivabe
- Duita device (PC + phone) khulun, dutoi token peyeche.
- PC-te ekta customer/memo likhun → phone-e **sathe-sathe** ashbe (laghbhag 0.1s)।
- Badge "Live" hole stream cholche.

## Kichu kharap hole
- Badge "Cloud degraded → Sheet" hole Worker-e pouchche na: `url` thik ache kina,
  ar device-e token bosa ache kina (Connect box) dekhen.
- Abar Firebase-e firte chan? `backend: 'firebase'` kore din — purono path hubohu
  pabe (code much jay ni).
- Data mitche na: Sheet mirror ta ekhono ache, tai ekta safety net sob somoy thake.
