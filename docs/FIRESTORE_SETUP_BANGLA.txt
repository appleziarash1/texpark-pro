TEXPARK PRO — CLOUD SYNC (FIRESTORE) SETUP GUIDE
================================================

Ei guide ta ekbar korlei hobe. Er por phone ar PC nijei nijei sync hobe.
Firebase er FREE plan e kaj kore — kono card lagbe na, kono server lagbe na.

GURUTTOPURNO: Firebase key ar project id ekhon app-er code-e (build-e) bosiye
dewa hoyeche. Tai kono device-e key bosate hobe NA. Jekono device e site khullei
cloud automatic set hoye jabe. Apni shudhu EKBAR email+password diye sign in
korben — bas.

Settings → "Cloud sync (Firestore)" e giye ei kaj gula korun:

------------------------------------------------------------------------
STEP 1 — Firebase project (ekbar, hoye geche)
------------------------------------------------------------------------
Project ta already banano: project id = texpark-62700.
Nao hoye thakle:
1. https://console.firebase.google.com khulun, Google account diye sign in korun.
2. "Add project" → nam din → Continue → Continue (Analytics off) → Create project.

------------------------------------------------------------------------
STEP 2 — Cloud account banan (ekta email/password)  ← ETA-I MAIN KAJ
------------------------------------------------------------------------
Ekta email diye account banate hobe. Ei email+password e PC ar phone duitai
sign in korbe, tai duitai EK TA account e thakbe.

1. Texpark Pro khulun → Settings → "Cloud sync (Firestore)".
2. "Cloud account (email)" box e email likhun (jemon: amar.dokan@gmail.com).
   Ei email ta Firebase project er moddhe ekta account, apnar asol email nao hote pare.
3. "Cloud password" box e ekta password din (kompokkhe 6 character).
4. "Create account" chapun.
5. "Sign in" chapun (jodi account age theke thake).
6. "Send all data to cloud" chapun — apnar shob purono data cloud e jabe.

Key ba project id kothao bosate hobe na — code-e ache.

------------------------------------------------------------------------
STEP 3 — Rules bosan (security)  ← ETA-I DATA SAFE RAKHE
------------------------------------------------------------------------
Firebase key public (eta diye keu apnar data dekhte parbe na). Security ta
Firestore Rules e. Eta bosan:

1. Firebase console → Build → Firestore Database → "Create database".
2. Location bachun → "Start in production mode" → Enable.
3. "Rules" tab e giye repo te thaka firestore.rules file er lekha paste korun → Publish.
   (Ei rule bole: keu nijer uid chara onner data porte/likhte parbe na.)

------------------------------------------------------------------------
STEP 4 — Phone/onno device  ← SHUDHU SIGN IN, key na
------------------------------------------------------------------------
1. Phone e site khulun → Settings → "Cloud sync (Firestore)".
   (Key/project id lage na — build-e ache, automatic.)
2. Same email + password diye "Sign in".
3. "Send all data to cloud" chapun (prothom bar).

Bas. Ebar jekono device e kichu change korle onno device e ~2 second e chole ashbe.

------------------------------------------------------------------------
KICHU JANAR MOTON KOTHA
------------------------------------------------------------------------
* Update koto druto ashe: app active thakle ~2 second, app idle thakle ~10
  second. Eta Firestore er realtime push na — kintu khub kache. Data thik
  thake, kichu hariye jay na.
* FREE plan e ki ki ase: 1 GB storage, din e ~50,000 read + 20,000 write.
  Apnar dokaner hisebe eta onek beshi. App sudhu ja bodleche setai pathay —
  pura boi na — tai limit er kache jaben na.
* Cloud fail korle (net nei / limit ses): app nijei Google Sheet e save kore
  rakhe, kichu hariye jay na. Cloud fire asle nijei abar sync suru kore.
* Status badge: "Firestore live" (thik ase), "Cloud degraded → Sheet"
  (cloud fail, Sheet cholche), "Cloud off (Sheet only)" (key dewa nai).
* Email/password karo sathe share korben na — eta diye apnar business data
  (memo, taka, stock) protected thake.
