# Texpark Pro — permanent hosting (step by step)

Ei repo-r **root ta-i pura app**. Kono build lagbe na, kono backend lagbe na.
GitHub Pages e upload korle **jiboneo off hobe na** — ar sob cheye bhalo dike,
Pages **nijei apnar site host kore**, alada kono account lagbe na.

Login: `admin` / `admin123`

Duita file:
- repo root (`index.html`, `js/`, `css/`) = pura app (folder) — PWA/install kaj kore
- `texpark-pro.html` = ek file e pura app — upload korte sohoj
  (kintu ei ek file theke "Add to Home screen" thik moto kaj na korte pare)

---

## Sob cheye bhalo: GitHub Pages (account lagbe na, alada kichu lagbe na)

Apnar repo ta-i site. Root-e `index.html` ache, tai `/` khulei app chalu hoy.

1. `https://github.com/appleziarash1/texpark-pro` khulun
2. **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)** — Save
5. 1-2 minute por link: `https://appleziarash1.github.io/texpark-pro`

Bas. Erpor apni jakhon repo-te notun code push korben (ba GitHub-er website theke
file edit korben), **site nijei update hobe** — abar kichu drop korte hobe na.
APK-r update check-o ei link-e ache, tai phone-e notun build nijei chole ashbe.

**Ekta kotha:** free plan-e Pages **public repo** te-i kaj kore. Repo public hole
keu apnar code dekhte parbe — kintu **business data dekhte parbe na**. Data apnar
phone-e ar apnar Google Sheet-e thake, duitai private. Ki dekha jay, ki jay na:
- Dekha jay: code, layout, khali app
- Dekha jay na: apnar memo, stock, customer, taka, Sheet-er data
- Ei karon `Code.gs`-e Sheet ID ta royeche — keu ID peye gelo o **kono data
  paben na**, karon Sheet ta private (login chara 401 ashe)

## Bikolpo: Netlify Drop (code na dekhate chan?)

Repo private rakhte chan, ba Netlify pochondo? Tahole ei ta:

1. Free account khulun: https://app.netlify.com/signup (shudhu email lagbe)
2. Login kora obosthay khulun: https://app.netlify.com/drop
3. **`texpark-hosting.zip`** file ta drag kore chere din (APK-o ei tar bhitor ache)
4. 20-30 second por ekta link pabben, e.g. `https://random-name-123.netlify.app`
5. **Settings → Change site name** diye naam din, e.g. `texpark-pro`
   -> link hobe `https://texpark-pro.netlify.app`
6. Erpor phone-e APK-r update address ta ei link-e set korun (Back button der khon
   chap diye menu theke)

**Important — agee ei kotha ta jene nin:** Netlify te **login na kore** (anonymous)
drag korle, site ta kichudin por nijei **password wall-er pichone chole jay**.
Tokhon ei message dekhben:

> Password protected site — Please enter your password to get access.

Ei password ta apni set koren ni, tai apnar jana nei. Eta Netlify-r nijer kora kaj,
ar free plan-e apni password ta bondho-o korte parben na (setting ta Pro plan-e ache).
Tai **age free account khulun, tarpor drag korun**.

**ZIP ta keno, folder ta keno?** Duitai cholbe. Kintu **folder-er ZIP** (`texpark-pro-download.zip`)
drop korle 404 ashe, karon tar root-e `index.html` thake na — thake
`texpark-pro-app/index.html`. `texpark-hosting.zip` ta ei jonno alada banano:
tar root-e `index.html` ache, tai `/` khulei app chalu hoy.

**Important:** ei link ta ei sandbox-er sathe kono somporko nei.
Sandbox jodi bondho o hoy, app cholbe.

### APK-o ei site-e roy — link ta kokhono purono hobe na

`texpark-hosting.zip`-er bhitor **`TexparkPro.apk`** o ache. Tai deploy korar
por ei link theke APK ta **jokhon khusi** abar download korte parben:

    https://<apnar-site>/TexparkPro.apk

Eta kaajer, karon sandbox-er link temporary, kintu site paka — tai APK-r link-o
paka. Phone change korle, notun phone-e install korte hole, ba karo phone-e
pathate hole — ei ek link-i jotheshto.

### 404 "Page not found" ashle ki korben

Ei message-er mane site ta cholche, kintu oi address-e kichu nei.

1. **Root address (`/`) e 404?** Tahole hoyto vhul zip/folder drop kora hoyeche.
   `texpark-hosting.zip` (root-e index.html) abar drop korun.
2. **Notun drop korchen?** 20-30 second opei thakun — deploy korte somoy ney.
3. **Dashboard → apnar site → Deploys** tab → dekhen sobcheye last deploy ta
   "Published" kina. "Failed" hole abar drop korun.
4. Dhyan din: address ta `/` e khuluk — `/texpark-pro-app/` e na.

### Keno account lagbe?

Account chara Netlify drop ta **temporary** — site ta claim na korle Netlify
kichudin por delete korte pare, ar tachara password wall-o boshiye dite pare.
Jei karon ei message ta ashe. Account banale site ta apnar list-e thake,
permanent hoy, ar update-o korte parben.

### Jodi password wall eshe jay

Netlify Dashboard → apnar site → **Project configuration → Access & security →
Visitor access** → Password Protection. Sekhan theke password ta remove korun
(ba set korun jodi sotti secret rakhte chan). Itar age sure korun site ta apnar
account-e claim kora ache — noile option ta lock thakbe.

## Data kothay thake?

Data apnar **phone/browser-e** thake (localStorage), hosting-e na.
Tai hosting bodlaleo data hariye jabe na — jeta oi browser e ache.
Kintu:

- **Backup nin:** Settings -> Backup / Data -> Export
- Notun phone-e giye oi backup file ta "Restore" kore din
- Browser cache clear korle data jete pare — tai backup niye rakha bhalo

---

## PC ar phone — duijonar data nijei mile jay

Age PC-te memo likhle phone-e dekhate "fire aan" chap dite hote chilo.
Ekhon ar dorkar nei: **app kholar shomoy nijei sheet theke notun data niye ashe**
(login korar somoy, ar abar tab-e fire ashle).

Ki kore:

1. App khule login korun — nijer data age sheet-e pathay
2. Tarpor sheet theke **sob device-er** data niye merge kore
3. Merged data abar sheet-e pathay, jate porer device pura chobi pay

Tai PC-te likha memo phone-e, ar phone-er memo PC-te — nijei chole ashbe.

**Gurutto-purbo kotha:** merge hocche, *replace* na. Tai:

- Dui device-e duita alada memo likhle **duitai thake**
- Ek memo dui jaygay edit korle **porer ta jite jay**
- Kono device theke memo delete korle **setha abar fire ashe na**
- Sheet na khule, internet na thakleo app **pura kaj kore**; porer bar nijei mile jay

**Bondho korte chan?** Settings -> Google Sheets Sync ->
*"Nijei sheet theke notun data niye ashe"* — tik tule din.
Tokhon shudhu apni chap dilei (Backup page -> "Ei device er backup fire aan") data nambe.

**Ekta tuku poramorsho:** duito device ek shomoy-e sheet-e likhle, shesher ta bhalo.
Tai ek device-e kaj korar por arek device-e jaoar age app ta ekbar khole nin.

## Keno permanent server ta ei sandbox e kora jay na?

Ei je machine ta ekhon amra use korchi seta ekta **temporary
sandbox** — kaj korar jonno bhara deya. Eta bondho hole server-o
bondho. Kono file rekhe dileo server cholbe na, karon cholano
machine ta-i nei.

Tai permanent hote hole **asar hosting** e uthate hobe. Netlify/
Vercel/GitHub Pages sob free ar permanent.

## Nijer PC theke cholate chaile

Ei folder ta rakhen. Internet na thakleo cholbe:

```
cd texpark-deploy
python3 -m http.server 8080
```

Tarpor browser e: `http://localhost:8080`

Kintu PC chalu na thakle phone theke access pabben na.
Tai Netlify Drop e kore fela-i bhalo.
