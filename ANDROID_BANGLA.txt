# Texpark Pro — Android app (install + update niyom)

## Ei app ta ki

Ei APK-er **bhitor-e apnar puro app ta ache** — index.html, css, code, sob.
Tai ei app ta **alada kono shell na**, puro app ta-i.

Ei karon-e duta boro subidha:

> **1. Install korar por kono address dite hoy na.** Tap korun, khulbe.
> **2. Internet na thakleo chole.** Dokane net na thakle-o memo, stock,
> hisheb sob kaj korbe.

Apnar data (memo, stock, customer, hisheb) apnar **phone-ei** thake. App-er
file ba data kothao pathano hoy na.

---

## Install korar niyom

1. `TexparkPro.apk` file ta phone-e nin (WhatsApp / email / USB / download link).
2. Phone-e file ta tap korun.
3. Android bolbe **"Unknown apps"** ba **"Install unknown apps"** permission
   chaibe — `Settings` e giye **Allow** korun. (Play Store chara app install
   korle ei permission lage; ei ta normal.)
4. **Install** chepun.
5. App khulbe — **bas, ar kichu lagbe na**. Kono address chaibe na.

### App ta kivabe cholbe

App khulle apnar sob kichu chalu — memo likhun, stock dekhen, hisheb korun.
Apnar data phone-e jome thake, tai app bondho korle-o thake.

---

## Net na thakle-o cholbe

Ei ta ei app-er sobcheye boro subidha. Dokaner net bondho, phone-er data
shesh, kothao net nei — **app ta tokhono kaj korbe**.

Net firle app nijei pichon theke taaza version niye ney (nicher section-e).

---

## Notun version kivabe ashe (nijei)

Apni site-e kichu bodlale (notun feature, design, dam er hisheb), ar
**Netlify-te abar drop korlen** — tarpor:

- Apnar phone, MD-saheb-er phone, dokaner PC — **sob jaygay app nijei niye ney**.
- App kholar somoy ekbar nijei jiggesh kore — "notun kichu ache?"
- Thakle **nijei neme ney**, ar **porer bar** app khulle notun ta chalu hoy.

Kakeo kichu pathate hobe na. "Update koro" bolte hobe na. Notun APK lagbe na.

| Ja bodlabe | Ki korte hobe |
|---|---|
| App-er kono feature, design, memo, stock, profit er hisheb | **Site-e upload korun** — app nijei niye nibe |
| App-er icon, app-er nam | Notun APK banate hobe |

**Net na thakle?** Kono somossa nei — bhitorer version ta-i chole. Net firle
porer bar nijei niye nibe.

### Update ta kokhono adhora theke jabe na

Notun version nemar somoy ek ta file na asle, app ta **purono version-ei thake**.
Adho-adhuri update kokhono boshbe na — mane app kokhono bhenge jabe na.

## Kichu bhul hole — Back button-er menu

App-er **Back button ta chhere dhore rakhun** (long press). Ek ta menu khulbe:

| Menu-r jinis | Ki kore |
|---|---|
| **Update chek korun** | Notun version ache kina ekhoni dekhe ney |
| **Update-er address bodlun** | Site-er address bodlanor jonno |
| **Built-in app-e ferot jan** | Nemar kora version muche, APK-er bhitorer version chalu kore |

"Sob kichu abar thik korun" chepun — app abar gari-r moto chole jabe.
**Apnar data muchbe na** — memo, stock, customer sob thake.

---

## Data kothay thake?

Bhoyer kichu nei — **data apnar phone-e-i thake** (`localStorage`).
Site update korleo data **thake na hariye** — karon app khollar somoy
shudhu **code** ashe, apnar data na.

Kintu ei kotha gulo mone rakhben:

- **Niyomito backup nin:** Settings → Backup / Data → Export. File ta
  Google Drive / email-e rakhen.
- **App uninstall korle data jabe** — tai age backup nin.
- **Restore korte:** Settings → Restore Backup → file ta bechhe nun.
- **Play Store na, sideload** — tai "Unknown apps" permission ta lage. Eta
  nirapod jodi apni nijei APK ta install koren.

## Technical kotha

- **minSdk 21** (Android 5.0+) — purono phone-o cholbe.
- **targetSdk 34** — notun Android-er niyom mane chole.
- **Permissions:** Internet, Network state, Record audio (voice entry-r jonno).
  Camera optional — na thakleo app install hoy.
- **Signed** — v1 + v2 + v3 signature soho, tai phone-e install hoy.
- **Voice entry** kaj korbe: app mic-er permission nijei dey, ar
  WebView-e `SpeechRecognition` support kore.
- **Print** kaj korbe: `window.print()` WebView-e print dialog kholay —
  sekhan theke **Save as PDF** o kora jay.
- **Backup export** kaj korbe: file gulo Downloads-e jome.

### APK-er bhitor ki bhore ache

- `assets/site/` — puro app (index.html, css, js, icon)
- `version.txt` — ei APK-e kono version ache (APK install-er somoy
  phone-er purono copy-er sathe tulona ei file diye hoy)

Phone notun version khuje pay **`js/app.js`**-er bhitor theke — karon eta
app-er nijer file, kono host er bhul page eta fake korte parbe na.

### Nijer APK ta notun kore banate chan?

Prothome deploy folder ta build korun, tarpor APK:

```
node texpark-pro/build.js
ANDROID_HOME=/path/to/android-sdk python3 build-apk.py
```

`build-apk.py` web app ta `texpark-deploy/` theke niye, `assets/site/` hishebe
APK-er bhitor boshay, ar verify kore je sob file sotti bhitor-e ache.
`TexparkPro.apk` root-e toiri hoy, `android-keystore.jks` diye sign hoye.

**Keystore file ta hariye fellen na** — ek-i keystore diye sign korle
purono app-er upore update install hoy; notun keystore hoile app ta notun app
hisebe dhore (purono ta uninstall korte hoy).
