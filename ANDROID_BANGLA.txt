# Texpark Pro — Android app (install + update niyom)

## Ei app ta ki

Ei app ta **puro asol Android app** — WebView na. Prottek screen asol Android
view diye toiri, ar apnar sob data phone-er **nijer database-e** thake, kono
website na.

Ei karon-e duta boro subidha:

> **1. Install korar por kono address dite hoy na.** Tap korun, khulbe.
> **2. Internet na thakleo chole.** Dokane net na thakle-o memo, stock,
> hisheb sob kaj korbe.

Apnar data (memo, stock, customer, hisheb) apnar **phone-ei** thake. App nijei
chaile chara kono data kothao pathano hoy na.

---

## Install korar niyom

1. `TexparkPro.apk` file ta phone-e nin (WhatsApp / email / USB / download link).
2. Phone-e file ta tap korun.
3. Android bolbe **"Unknown apps"** ba **"Install unknown apps"** permission
   chaibe — `Settings` e giye **Allow** korun. (Play Store chara app install
   korle ei permission lage; ei ta normal.)
4. **Install** chepun.
5. App khulbe — **bas, ar kichu lagbe na**. Kono address chaibe na.

### App ta kivabe cholbe

App khulle apnar sob kichu chalu — memo likhun, stock dekhen, hisheb korun.
Apnar data phone-e jome thake, tai app bondho korle-o thake.

---

## Net na thakle-o cholbe

Ei ta ei app-er sobcheye boro subidha. Dokaner net bondho, phone-er data
shesh, kothao net nei — **app ta tokhono kaj korbe**.

Net firle app nijei pichon theke taaza version niye ney (nicher section-e).

---

## Notun version kivabe ashe

Notun version site-e deoya hoy (host-er upore `TexparkPro.apk` ta thake).
App kholar somoy nijei jiggesh kore — "notun kichu ache?" Thakle ek ta
**dialog** ashe: **Download** chepun.

- **App nijei install korte pare na.** Android 8 theke ek ta app nijer APK
  install korte pare na — ei ta Android-er niyom, kono durbalta na. Tai
  Download chepuk, file ta neme asbe, tarpor **file ta tap korun** —
  Android install korte bolbe (**Install** chepun).
- **Apnar data muchbe na.** Update hole memo, stock, customer sob thake —
  shudhu code ta notun hoy.
- **Net na thakle?** Kono somossa nei — app chole, kichu jiggesh kore na.
  Net firle porer bar nijei dekhbe.

### Update ta kokhono adhora theke jabe na

Site-e notun APK na thakle, ba adha-adha nemar somoy kichu bhul hoile, app ta
**purono version-ei thake**. Adho-adhuri update kokhono boshbe na — mane app
kokhono bhenge jabe na.

## Kichu bhul hole — Back button-er menu

App-er **Back button ta chhere dhore rakhun** (long press). Ek ta menu khulbe:

| Menu-r jinis | Ki kore |
|---|---|
| **Update chek korun** | Notun version ache kina ekhoni dekhe ney |
| **Update-er address bodlun** | Je site theke update ashe, sei address bodlanor jonno |

"Sob kichu abar thik korun" chepun — app abar gari-r moto chole jabe.
**Apnar data muchbe na** — memo, stock, customer sob thake.

---

## Data kothay thake?

Bhoyer kichu nei — **data apnar phone-er nijer folder-e** thake (`getFilesDir()`),
kono onno app eta porbe na. Site update korleo data **thake na hariye** — karon
app khollar somoy shudhu **code** ashe, apnar data na.

Kintu ei kotha gulo mone rakhben:

- **Niyomito backup nin:** Settings → Backup / Data → Export. File ta
  Google Drive / email-e rakhen.
- **App uninstall korle data jabe** — tai age backup nin.
- **Restore korte:** Settings → Backup / Data → file ta bechhe nun. App
  prottek save-er age ek ta **safety copy** o rakhe, tai bhul hoye gele-o
  pichon-er obosthay ferot jawa jay.
- **Play Store na, sideload** — tai "Unknown apps" permission ta lage. Eta
  nirapod jodi apni nijei APK ta install koren.

## Technical kotha

- **minSdk 21** (Android 5.0+) — purono phone-o cholbe.
- **targetSdk 34** — notun Android-er niyom mane chole.
- **Permissions:** Internet, Network state. Mic-er permission app chay na —
  voice entry mic ta **system-er voice recogniser** ke dey, se-i record kore.
  Camera optional — na thakleo app install hoy.
- **Signed** — v1 + v2 + v3 signature soho, tai phone-e install hoy.
- **Voice entry** kaj korbe: `RecognizerIntent` (Bangla) diye kotha ney, ar
  `TextToSpeech` diye uttor bole. Kono phone-e ei duita na thakle app tobuo
  chole, sudhu voice ta kaj korbe na.
- **Print** app theke hoy na. Apni bolechen phone theke print korte hobe na,
  tai memo ta phone-i **dekhanor** jonno toiri — Memo History → memo → sob
  kichu puro dekha jay. PC theke print korte chan to web app ta khulun.
- **Backup export** kaj korbe: backup file app-er **nijer private folder**-e
  jome (`getFilesDir()`), kono onno app eta porbe na.

### App ta kemon bhabe banano

Ei app ta **puro native** — WebView na. Prottek screen asol Android view
(`TextView`, `EditText`, `ScrollView`) diye toiri. Er karone:

- memo/stock/customer — sob **app-er nijer folder-ei** JSON database-e thake,
  kono internet lage na, kono host down holeo app chole.
- **Age WebView chilo, ekhon nei.** Purono version ta WebView-e site ta
  dekhacho, ar tokhon duta asol somossa chilo: memo print kora jeto na
  (`window.print()` WebView-e kichui kore na), ar phone-er asol keyboard,
  date picker, voice — kichui thik moto kaj korto na. Sei karone app ta puro
  native kora hoyeche.
- **Kono screen khali asbe na.** `test/native.test.js` dekhe je menu-r prottek
  item-er jonno ek ta screen ache, ar kono file WebView ba `window.print`
  firiye aneni.

### APK-er bhitor ki bhore ache

- `classes.dex` — puro native app-er code
- `res/drawable/ic_launcher.png` — nijer icon
- `resources.arsc`, `res/` — icon ar Android-er resource
- `version.txt` APK-er bhitor na — eta host-e thake, ar app kholar somoy
  `js/app.js` theke version ta pore. Tarpor nijer version-er sathe milay:
  notun hole dialog dey, na hole chup thake.

### Nijer APK ta notun kore banate chan?

```
node texpark-pro/build.js
ANDROID_HOME=/path/to/android-sdk python3 build-apk.py
```

`build.js` age `version.txt` likhe, ar `build-apk.py` sei version ta
`MainActivity.java`-er bhitor stamp kore — tarpor compile kore. Ei karone
Settings-e ja version dekhi, ar update check-e ja mile, ek e hoy.

`build-apk.py` verify kore je APK-e `classes.dex` ache ar version ta
dex-er bhitor sotti ache — ekta khali APK install hoye khola-matra bondho
hoye jeto, ar apksigner seta signature diye dito.

`TexparkPro.apk` root-e toiri hoy, `android-keystore.jks` diye sign hoye.

**Keystore file ta hariye fellen na** — ek-i keystore diye sign korle
purono app-er upore update install hoy; notun keystore hoile app ta notun app
hisebe dhore (purono ta uninstall korte hoy).
