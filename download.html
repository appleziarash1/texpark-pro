Kivabe khulbo

Phone-e chalate

  1. ZIP-er bhitor thika texpark-pro.html file ta ber korun.
  2. File ta WhatsApp / email kore nijer phone-e pathaan, ba USB diye kopi korun.
  3. Phone-e file ta khulun (Files app → file-e tap) → Chrome browser e khulbe.
  4. Browser-er menu (⋮) → "Add to Home screen" chepun. Icon hoye jabe — internet charao khulbe.
Phone-e ekbar khular por Settings → Device Tag e PH boshiye din. Ar PC-te PC. Tahole memo number kokhono clash korbe na.

PC-te chalate

  1. ZIP ta Right click → Extract All diye khulun.
  2. texpark-pro-app folder-er bhitor OPEN_APP.bat e duibar click korun — app browser-e khulbe. Ei file ta kichu install kore na, sudhu app ta kholay. Node.js lage na.
  3. Desktop-e shortcut chai? CREATE_DESKTOP_SHORTCUT.bat chepe nin — desktop-e icon hoye jabe. (Shortcut-er maddhome chalate Node.js lage; na thakle browser-e index.html bookmark kore rakhen.)
Windows-er ashol .exe app chan? Node.js LTS install kore folder ta te npm run dist chepun — dist folder-e setup file toiri hobe, jeta onno PC-te install kora jabe.
